# Дорожная карта

1. **Один автономный агент (текущий этап).** Вход Atlas, JSON-решения OpenRouter, сбор древесины, изготовление верстака/кирки, разговор с тестовым игроком и сохранение после перезапуска проверены. Дальше проверить вход с Windows, строительство, пищу, бой и устойчивость длительной сессии; см. `TEST_REPORT.md`.
2. **Голос через Discord.** После стабилизации текстового общения добавить двусторонний голосовой интерфейс.
3. **Расширенная эпизодическая память.** Сначала оценить ограничения текущего JSON-файла; только затем выбирать хранилище и поиск.
4. **Безопасное создание навыков.** Отдельно квалифицировать изолированное выполнение на ARM64 перед включением генерируемого кода.
5. **Несколько автономных агентов.** Использовать существующий multi-bot режим и проверить координацию на общем мире.
6. **Поселение и сообщество.** Исследовать обмен ресурсами, совместное строительство и возникающее сотрудничество после надёжной работы нескольких агентов.

Этапы 2–6 не реализованы в этой конфигурации.
